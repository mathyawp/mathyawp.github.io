Mechanism

Test 1 — the PDE

φ″/φ = λx2 and −ψ″/ψ = λy2 are both constants. Δu = 0 exactly when they agree, so close the coral band.

What am I looking at?

The same plate as The Fourier Question, but one step earlier in the argument. Fourier looked for solutions of the special form u(x,y) = φ(x)ψ(y) — a function of x times a function of y. Here φ decays and ψ oscillates, and you set the rate of each independently.

The layout is the algebra. The teal curve down the left is ψ(y); the amber curve along the bottom is φ(x); the plate between them is their product. Hover anywhere on the plate and it will show you the two factors it multiplied.

Test 1. Feed u into the Laplacian and the derivatives fall on separate variables: Δu = (λx2 − λy2)u. The residual is a scaled copy of u itself, so it can only vanish when the scalar does — when λx = λy. That is a continuous condition: any common value works. Watch the Δu inset go black as you close the band.

Test 2. The top and bottom edges are held at 0, so ψ(±1) = cos λy must be 0. That is a discrete condition: λy ∈ {π/2, 3π/2, 5π/2, …}, which is exactly (2k+1)π/2. The eigenvalues are not handed down — they are whatever survives both filters.

Each surviving mode solves the problem exactly, with no analysis needed. So does any finite sum of them, since Δ is linear. Whether an infinite sum still does, and whether it can match an arbitrary edge temperature, is the question the next visualization opens. Press Space or Enter on a switch to toggle it.
