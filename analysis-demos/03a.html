Making the Gap Small

Can a partition make the gap smaller than ε?

On each interval, multiply the oscillation Mᵢ−mᵢ by the weight Δαᵢ. Integrability asks whether some partition makes the sum of these contributions arbitrarily small.

Why does this work?

How can we make the gap small?

Continuity

On sufficiently short intervals, Mᵢ−mᵢ is small.

Constant values of α

If Δαᵢ=0, that interval contributes zero.

Common refinement

Lower sums increase and upper sums decrease under refinement.

What should we remember?

The Cauchy criterion requires U(P)−L(P)<ε.

Given ε > 0, choose a partition P so that U(P) − L(P) < ε. Doing this for every ε > 0 proves that f is integrable.
